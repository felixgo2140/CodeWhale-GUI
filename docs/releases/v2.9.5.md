# CodeWhale GUI v2.9.5

本版本完成安装器、在线更新、语音整理和多模型对比链路的收尾加固，并同步发布元数据与签名校验。

## 安装器与真实版本就绪校验

- 安装器保留已有配置、MCP、插件和登录状态，同时继续校验敏感文件权限、Universal 双架构原生 App 与代码签名。
- 安装后不再只等待进程或端口：安装器轮询 `http://127.0.0.1:3000/healthz`，要求返回的版本与本次安装的 `VERSION` 完全一致，避免旧 GUI 进程被误判为新版本已就绪。

## 在线更新错误提示

- 更新检查明确区分网络错误与签名错误。
- 断网、DNS、连接超时等网络问题不再误报首页红色失败条；签名无效和其他真实错误仍保留可见提示。

## 模型与语音体验

- 删除余额探测死代码，移除无效余额接口和重复探测路径。
- 语音整理失败或远端模型不可用时保留本地整理结果，并显示具体原因，包括整理超时、模型不可用、无直连模型和请求失败。
- 对比窗口表头模型选择与实际请求路径共用同一模型偏好；异步偏好加载后刷新已有表头，不丢失正在显示的回答。

## 发布链路

- `make-release.sh` 默认使用收紧后的专用发布私钥路径。
- 构建前强制核对签名私钥对应的 Ed25519 公钥与 `server.py` 内嵌的 `GUI_UPDATE_PUBKEY_B64` 完全一致，防止生成客户端无法验签的 Release。
