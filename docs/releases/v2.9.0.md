# CodeWhale GUI v2.9.0

这是一次完整发布：组合调度工作台与最新稳定性修复一起进入可在新 macOS 用户环境安装的发布包。

## 组合模型

- 新增独立「组合模型」窗口，侧栏按唯一会话编号归组，不会混入单模型或多模型对比。
- 控制者与执行者均可配置，后续切换 Kimi、Qwen、GPT 或其他已接入模型时无需改工作流代码。
- 控制者先展示对任务的理解、边界与路线；执行者仅在研究、起草、读写文件、运行命令或测试确有需要时介入。
- 简单任务直接完成；一般任务进行一次复核与执行后收敛；高风险任务保留确认点和最终验收。修复回合有上限，避免反复审计和重复消耗。
- 任务运行期间可在输入框发送「引导」，即时补充约束或改变方向。

## 完整安装

下载 `codewhale-installer.tar.gz`，解压并双击 `install.command`。

安装器会：

1. 检查 Node.js 与 Python 3，并在当前用户目录安装兼容的 CodeWhale CLI；不使用 `sudo` 或全局 npm。
2. 安装 GUI、后端、Harness 与同时兼容 Apple Silicon 和 Intel 的原生 `CodeWhale.app`。
3. 保留已有的模型配置、OAuth、MCP、插件、会话和 token；只补充 CodeWhale 自带的 fetch/playwright MCP，不覆盖自定义服务。
4. 不携带任何 API key、OAuth 凭据、会话数据或发布私钥。

本次在线更新的签名信任链已更新。使用早期版本的用户请先运行一次本完整安装包；之后即可继续使用应用内的签名更新。

## 发布验证

发布前已在临时空白 HOME 中实际执行安装，验证安装 payload、配置与 MCP 合并、文件权限、LaunchAgent、通用二进制签名和 GUI 启动。完整 Python 回归套件也已通过。
