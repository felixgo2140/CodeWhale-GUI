# CodeWhale GUI v2.9.2

这是一次模型兼容、任务路由和输入可靠性更新。重点修复 Qwen 3.8、Kimi/Moonshot 工具参数兼容、多模型汇总操作与批量附件，并补齐模型目录自动发现。

## 模型与路由

- Qwen 统一迁移到阿里云 Token Plan 协议和端点。
- 启动与更新中心可从 `/models` 自动发现同一 API 下全部可对话 Qwen / QwQ 模型，并过滤嵌入、语音、图像和视频模型；不自动切换已有会话。
- 当前对话切换模型后，线程级 provider/model 会立即成为界面唯一状态；后台迟到的默认模型请求和侧栏轮询不能再把左下角模型名覆盖回旧值。
- Qwen 聊天请求强制使用安全的 IPv4 POST，API key 不出现在进程参数中。
- 修复 Kimi/Moonshot 遇到不支持的 MFJS/JSON Schema 关键字时整轮失败；工具参数会在发送前做兼容清洗。
- 简单问题优先走快速模型，复杂任务和工具任务保留推理模型，避免单位换算等短问答长时间等待。

## 对比、回复与任务恢复

- 多模型汇总恢复「复制全部回复」和「一键总结」，并保留 Markdown 阅读体验。
- 回复操作统一提供复制、在新任务中继续和引用为上下文。
- provider 生命周期与中断恢复进一步收敛，避免健康后端被 GUI 重启无条件终止。
- 修复回复选项识别、组合任务信封拆分和新对话默认设置的边界问题。

## 附件队列

- 单条消息现在最多可加入 12 个附件，单个文件上限保持 50MB。
- 文件选择器会先复制完整的 `FileList`，避免 WebKit 在清空或再次打开选择器时丢失后续文件。
- 一批附件会先完整显示在输入框上方，再以最多 3 路并发上传，不再让第三个及之后的文件静默消失。
- 支持分批继续添加附件；按钮会显示当前附件数量。
- 自动跳过同一批次的重复附件，并明确提示超限、重复或过大的文件。
- 后端继续为同名文件生成独立文件名，避免覆盖已有附件。

- 完整 Python 回归套件通过。
- JavaScript、Python 与发布脚本语法检查通过。
- 发布包在隔离的空白 HOME 中执行首次安装验证，检查配置保留、MCP 合并、权限、通用二进制签名与 GUI 启动。
