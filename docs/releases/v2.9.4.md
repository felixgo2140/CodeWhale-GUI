# CodeWhale GUI v2.9.4

本版本恢复 GUI 新版本在首页的明确提示，并修复在线更新发布签名链不一致的问题。

## 首页更新提示

- 检测到新 GUI 版本后，在主界面顶部显示常驻通知条，包含目标版本、发布说明和“立即更新”按钮。
- 点击通知会直接打开 GUI 更新详情，可继续执行下载、Ed25519 验签、SHA-256 校验、替换和重启。
- 侧栏顶部的小型更新按钮继续保留，首页通知不再依赖侧栏宽度或用户是否打开设置页。
- 更新检查失败时首页显示可读错误，避免异常信息为空时整项提示静默消失。

## 发布签名链

- 修复发布脚本默认使用了错误私钥、导致 Release manifest 无法通过现有客户端内置公钥验证的问题。
- v2.9.4 使用与客户端既有信任锚匹配的 Ed25519 私钥签名，已安装的 v2.9.3 客户端可重新发现并验证最新版。
- 发布前新增强制一致性检查：签名私钥对应的公钥必须与 `server.py` 内置公钥完全一致，否则发布脚本立即失败。

## 发布验证

- GUI 更新版本比较、无效签名错误、首页通知渲染和通知按钮入口均有自动化回归覆盖。
- 完整 Python 自动化与 JavaScript、Python、Shell 语法检查通过。
- 正式发布包通过签名信任锚、SHA-256、隔离首次安装、配置与 MCP 保留、Universal App、代码签名和 GUI 启动验证。
