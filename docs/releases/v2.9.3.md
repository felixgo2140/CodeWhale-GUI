# CodeWhale GUI v2.9.3

这次更新专门修复模型被意外切换、界面模型状态不同步，以及语音口述整理偶发失败的问题。

## 模型选择

- 取消“简单问题快答”自动判断与模型切换。短消息、简单描述和普通问题都继续使用当前任务中由用户明确选择的模型。
- 启动时自动恢复并清理旧版本遗留的快答路由，避免已有任务再次显示 Qwen 3.7 Plus 等旧快速模型。
- Qwen/Kimi 的工具兼容委派仍然保留，但只在提示明确要求搜索、读取网页、运行命令或处理文件时临时使用；任务完成后恢复原模型。
- 左下角只保留一个权威模型选择器，移除右侧容易滞后和不同步的重复 provider/余额文字。

## 语音整理

- 语音 prompt 整理与正常模型聊天共用同一条 provider 调用链，Qwen Token Plan 请求继续强制使用 IPv4。
- 放宽 Qwen 3.8 等模型的整理等待时间，避免模型即将返回时被旧的 8 秒限制提前中断。
- 模型临时不可用时仍立即保留口述并执行本地整理，界面显示“已转写 · 本地整理”，不再把成功保留的输入误报为模型故障。

## 安装与更新

- 安装或覆盖升级后强制重载 GUI 服务，保证磁盘上的新代码与正在运行的 Python 进程完全一致。
- 安装完成前同时验证后台服务端口 7878 和 GUI 端口 3000，任一未就绪都会明确报错。

## 发布验证

- 完整 Python 自动化回归套件通过。
- JavaScript、Python 与安装脚本语法检查通过。
- 实机验证 Qwen 3.8 语音整理成功、旧快答路由清零、重复模型标签消失。
- 完整安装包在隔离 HOME 中验证首次安装、原配置与 MCP 保留、敏感文件权限、Universal App、代码签名和 GUI 启动。
