# CodeWhale GUI v2.9.1

这是一次附件可靠性更新，修复单模型和多模型对比中一次只能稳定加入两个附件的问题。

## 附件队列

- 单条消息现在最多可加入 12 个附件，单个文件上限保持 50MB。
- 文件选择器会先复制完整的 `FileList`，避免 WebKit 在清空或再次打开选择器时丢失后续文件。
- 一批附件会先完整显示在输入框上方，再以最多 3 路并发上传，不再让第三个及之后的文件静默消失。
- 支持分批继续添加附件；按钮会显示当前附件数量。
- 自动跳过同一批次的重复附件，并明确提示超限、重复或过大的文件。
- 后端继续为同名文件生成独立文件名，避免覆盖已有附件。

## 发布验证

- 完整 Python 回归套件通过。
- JavaScript 与发布脚本语法检查通过。
- 发布包在隔离的空白 HOME 中执行首次安装验证，检查配置保留、MCP 合并、权限、通用二进制签名与 GUI 启动。
